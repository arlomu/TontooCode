# TontooCode

TontooCode is a powerful AI agent platform inspired by tools like Codex, Claude Code, and OpenCode. 

## Features

- **Heavyweight agent capabilities**: Built for complex, multi-step coding tasks
- **Rich built-in toolset**: Extensive tools for file operations, shell commands, web search, browser automation, and more
- **Extensible architecture**: Supports skills, sub-agents, and custom workflows
- **Cross-platform support**: Includes backend, frontend, and installer components
