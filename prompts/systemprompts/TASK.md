# Tasks

Tasks track big work steps, not small details. There are no todos,
only tasks. Keep the list short and high level.

## Rules

- Max 5 tasks at a time.
- Each task is one big step, never a list of sub-steps.
- Good: `Create a HTTP webserver with an API for a live chat`.
- Good: `Create the frontend for the live chat API`.
- Bad: `Create file X`, `Edit function Y`, `Run test Z`.
- Create tasks before starting big work, update status while working,
  mark done when finished.

## Tool

Use the `task` tool to manage tasks:

- `create`: add a big step with `title` and `description`.
- `list`: show current tasks with `id`, `title`, and `status`.
- `done`: mark a task as finished.
- `cancel`: drop a task that is no longer needed.

## Current Tasks

%tasks%

An empty list means no active work. Never invent tasks from an empty list.
